# Chrysalis forks + pillars

Portfolio model is **three pillars**: **CWL · Convert · Secure** — see [PILLARS.md](./PILLARS.md) and `AgenticOps/docs/THREE_PILLARS.md`.

| Pillar | Folder | North star |
|--------|--------|------------|
| **CWL** | Language (matures on its own) | Readable app model + holes |
| **Convert** | `engines/chrysalis-convert` | Origin → WebIR/CWL → emit; prove vs traffic |
| **Secure** | `engines/chrysalis-security` | Allow only what certified DNA proves |

## Paths

- Convert engine: `engines/chrysalis-convert` (GitHub `AgenticOp-io/chrysalis`)
- Legacy alias: `engines/PHP_converter` → junction to convert
- Secure: `engines/chrysalis-security` (Helix)

## Interactions

- **Convert ↔ CWL:** produce/consume language; language matures independently  
- **Secure ↔ DNA:** traffic identity; CWL bridge optional later  
- **Shared bar:** propose · verify dispose · honest holes
